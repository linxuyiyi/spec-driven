# 参数约束用例分析规则

## 核心前提

基站端有约束校验机制，所有不符合约束的配置在 MML 命令执行阶段就会被拒绝，**不会出现不符合约束的配置实际生效的情况**。

测试的核心目标是：**验证约束校验是否正确拦截非法配置。**

## 约束类型

| 约束类型 | 描述 | 示例 |
|----------|------|------|
| 联动约束 | A 开启时 B 必须满足条件 | 开启 CA 时辅载波频段必须兼容 |
| 互斥约束 | A 和 B 不能同时存在 | DSS 模式与独立部署互斥 |
| 范围约束 | 参数值必须在有效区间内 | 发射功率 0-50dBm |
| 枚举约束 | 参数只能取特定离散值 | 子载波间距 15/30/60/120 kHz |
| 条件约束 | 参数可配置性取决于上下文状态 | NSA 模式下某些参数不可配置 |
| 共存约束 | 多功能共存时的限制 | 4G/5G 共站总功率上限 |

## 约束校验的触发与响应

- **触发方式**：执行 MML 命令时即校验
- **校验结果**：拒绝配置并返回错误（错误码 + 错误信息）
- **配置不会部分生效**：要么命令执行成功，要么被拒

## 用例名称解析模式

```
【参数约束】{编号}：{约束描述}
```

从约束描述中提取：
- **被约束对象**：哪个参数/功能受约束
- **约束条件**：什么条件下约束生效
- **约束结果**：允许还是禁止某种操作

## 检查维度

### 1. 约束规则完整性

- [ ] 约束规则的触发条件是否明确？（什么操作触发校验）
- [ ] 约束的目标参数是否完整？（参数路径、当前值、目标值）
- [ ] 约束违反时的错误反馈是否明确？（错误码、错误信息）

### 2. 前置条件检查

- [ ] 基站/小区的运行状态是否明确？
- [ ] 被约束参数的初始值是否明确？
- [ ] 相关依赖参数的状态是否明确？
- [ ] 网络环境要求是否明确？（SA/NSA、频段、带宽、组网方式）

### 3. 测试步骤检查

- [ ] 正向步骤（约束允许的操作）是否有？
- [ ] 负向步骤（约束禁止的操作，预期被拒绝）是否完整？
- [ ] 是否需要测试批量场景？

### 4. 预期结果检查

- [ ] 正向操作的成功标准是否可判定？
- [ ] 负向操作的拒绝标准是否可判定？（返回错误码/错误信息）
- [ ] 拒绝后参数是否保持原值不变？

### 5. 后置条件检查

- [ ] 是否需要删除创建的小区/网元？
- [ ] 是否需要恢复参数初始值？
- [ ] 无需恢复？
